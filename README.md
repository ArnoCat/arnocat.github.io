# ArnoCat Blog

这是一个基于 Hugo 和 PaperMod 的静态博客项目，发布目录为 `docs/`。

## 本地开发

1. 安装 Hugo Extended
2. 在项目根目录运行 `hugo server -D`
3. 打开本地预览地址查看效果

## 生产构建

运行 `hugo` 后，生成产物会输出到 `docs/`。

## 目录说明

- `content/` 放文章与页面内容
- `layouts/` 放自定义模板覆盖
- `assets/css/extended/custom.css` 放站点扩展样式
- `themes/PaperMod/` 为当前主题
